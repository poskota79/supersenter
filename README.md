# Supersenter

A modern, responsive static website built with pure HTML and CSS.

## 📋 Contents

- **index.html** - Main landing page with navigation, hero section, services, and contact
- **styles.css** - Responsive stylesheet with mobile-first design
- **README.md** - This file

## 🎨 Features

- Fully responsive design (mobile, tablet, desktop)
- Sticky navigation header
- Hero banner with call-to-action
- About section
- Services grid layout
- Contact section
- Clean, modern styling
- Accessibility-friendly semantic HTML

## 🚀 Quick Start

1. Clone this repository:
   ```bash
   git clone https://github.com/poskota79/supersenter.git
   cd supersenter
   ```

2. Open in your browser:
   - Simply open `index.html` in your web browser, or
   - Use a local server:
     ```bash
     python -m http.server 8000
     # or
     npx http-server
     ```

3. Visit `http://localhost:8000` in your browser

## 🎯 Customization

### Update Content
Edit `index.html` to:
- Change the site title and navigation
- Update section content
- Modify links and email addresses
- Add or remove sections

### Update Styling
Edit `styles.css` to:
- Change colors in the `:root` CSS variables
- Adjust typography and spacing
- Modify responsive breakpoints
- Add animations or transitions

### Change Colors
Update these variables in `styles.css`:
```css
--primary-color: #0066cc;     /* Main brand color */
--secondary-color: #f0f2f5;   /* Background accent */
--text-color: #1a1a1a;        /* Primary text */
--light-text: #666;           /* Secondary text */
```
